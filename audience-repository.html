人群仓库

录入达摩盘人群包信息，上传已整理好的维度占比表，后续可直接被投放分析、GenBI 和策略复盘调用。

批量导入标签提取表

上传“人群仓库_标签提取.xlsx”，系统会按达摩盘人群包 ID 批量同步。表里已有的人群会自动覆盖旧记录，新的人群会新增。

新增人群

直接填写人群基础信息，并上传“人群仓库_图片数据提取.xlsx”。系统会读取“人群仓库ID / 维度 / 分类 / 分析人群占比”的长表数据。
