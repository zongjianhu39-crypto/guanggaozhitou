UI 重设计方案

交个朋友 · 广告智投工作台 — 从「功能目录」到「智能总控台」

一、现状诊断

1

配色单一

全站紫色渐变贯穿，缺乏层次区分，长时间使用视觉疲劳

2

内联样式泛滥

GenBI、看板、洞察中心等页面 style 堆积数百行，难以维护

3

页面风格割裂

首页精致、看板朴素、GenBI 又是另一套视觉语言

4

导航信息过载

6+ 入口平铺在顶部，投手/运营/管理者没有差异化入口

5

移动端适配弱

Hero 双栏在小屏幕折叠体验差，表格不可横向滚动

6

数据缺视觉焦点

核心指标（ROI、花费）与普通信息层级相同，难以快速判断

7

交互反馈不足

hover 效果单调，状态切换无动效，操作无确认反馈

二、设计原则

  1. 数据优先 — 用户打开页面的第一眼，看到的是关键数据，不是大段文案
  2. 状态可视化 — 用色彩语义（绿/黄/红）让指标状态一目了然，降低认知负担
  3. 角色差异化 — 投手看表现、运营看异常、管理者看结论，同一平台三种入口体验
  4. 一致性 — 所有页面共享同一套 Design Token，视觉语言统一
  5. 渐进展示 — 先给结论，再给细节；先给概览，再给明细

旧方案

  • 左右两栏：问答 + 示例
  • 示例区占据大量空间
  • 结果展示区域小
  • 文件上传入口不明显

五、组件规范

5.1 导航栏

  • 深色背景（Indigo 800）+ 白色文字，sticky 定位
  • Logo 左侧，导航项右侧，支持移动端汉堡菜单
  • 当前页高亮用底色 pill 形式，hover 用透明度变化
  • 「更多」下拉菜单使用圆角卡片 + 阴影

5.2 指标卡片

  • 顶部 3px 彩色状态条：靛蓝=通用、绿=正向、黄=波动、红=异常
  • 标签灰色小字 + 数字大号加粗 + 变化率彩色
  • hover 时微微上移 + 阴影增强

5.3 分段选择器

  • 替代老式 Tab：灰色底 + 白色/主色活跃项
  • 活跃项带圆角 + 微阴影，切换有 200ms 滑动动效

5.4 按钮

  • 主按钮：主色背景 + 白色文字 + 圆角 8px
  • 次按钮：白底 + 边框 + 深色文字
  • 文字按钮：无边框 + 主色文字
  • 所有按钮 hover 有 translateY(-1px) + 阴影增强

5.5 表格

  • 表头浅灰底 + 小号加粗，数据行白底
  • 行 hover 浅灰高亮
  • 状态列使用彩色标签
  • 支持横向滚动 + 固定首列

七、实施路线

  1. Phase 1 — 基础设施（1-2 天）
    • 创建 assets/css/tokens.css 统一 Design Token
    • 更新 global.css 引入新 Token
    • 抽离各页面内联样式到独立 CSS 文件
  2. Phase 2 — 导航 & 框架（1 天）
    • 统一导航栏组件
    • 深色导航栏替代白色导航栏
  3. Phase 3 — 首页重设计（2-3 天）
    • Hero 区从营销型改为数据总控台
    • 核心指标行 + 趋势图 + 角色入口
  4. Phase 4 — 数据看板重设计（2-3 天）
    • 指标卡片加状态条
    • 分段选择器替代 Tab
    • 异常预警独立面板
  5. Phase 5 — GenBI & 洞察中心（2-3 天）
    • GenBI 对话式布局
    • 洞察中心风险等级色标
  6. Phase 6 — 其他页面 & 响应式（2 天）
    • 计划拆解、Prompt 管理、规则管理页面统一样式
    • 响应式适配和微动效
